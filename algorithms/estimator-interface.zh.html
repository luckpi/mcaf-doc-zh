5.4.1. 固件接口¶

5.4.1.1. 概述¶

MCAF 中的位置和速度估计器具有几个共同特性。本节描述它们的方法、类型和语义。一个名为 Xyz 的虚构估计器将用于示例目的。

5.4.1.2. 术语¶

MCAF 中使用以下术语来描述估计器：

术语

描述

活跃

活跃估计器正在运行并确定角度和速度。（在 motorBench 的 Customize（自定义）页面中选择® Development Suite（开发套件）中的所有估计器默认为活跃状态。）

主

主估计器确定用于换相和反馈的角度和速度。多个估计器可以同时活跃，但在任何给定时刻只能有一个主估计器。

侵入式

侵入式估计器是用某种激励波形扰动控制器输出的估计器，可能对电机电流和电压有轻微影响。非侵入式估计器通过现有的电流、电压或其他传感器测量来确定角度和速度，除了作为主估计器使用外不影响运行。大多数估计器是非侵入式的。

5.4.1.3. 文件系统位置¶

使用估计器的调用点可在 commutation.c 和 commutation.h中找到;存储声明在 commutation_types.h。

各个估计器模块的实现位于 commutation 目录中。它们通常至少包含一个 .h 文件和一个 .c 文件，例如 commutation/xyz.h 和 commutation/xyz.c。一些估计器模块将类型定义单独放在 types.h 文件中，例如 commutation/xyz_types.h。估计器的状态变量结构定义在 types.h 文件中（如果存在），连同内联静态获取方法;否则定义在主 .h 文件中。函数原型声明在主 .h 文件中。

估计器特定参数（如延迟、限制和调节增益）生成在 parameters/xyz_params.h。

5.4.1.4. 存储和类型¶

每个估计器都有一个状态变量结构定义在 commutation/xyz.h 或 commutation/xyz_types.h，例如：

// 供 Xyz 估计器使用的状态变量结构
typedef struct tagMCAF_ESTIMATOR_XYZ {
   ...
} MCAF_ESTIMATOR_XYZ_T;

此状态变量结构的存储将声明在 commutation_types.h，通常如下所示：

/**
 * 用于比较估计器电气角度的相对角度
 */
typedef struct tagMCAF_RELATIVE_ANGLE_T
{
   MCAF_U_ANGLE_ELEC qei; /** 带速度跟踪环的正交编码器 */
} MCAF_RELATIVE_ANGLE_T;

/**
* 位置/速度的状态估计器数据
*/
typedef struct tagMCAF_ESTIMATOR_T
{
   MCAF_ESTIMATOR_QEI_T qei;  /** 带速度跟踪环的正交编码器 */
   MCAF_ESTIMATOR_XYZ_T xyz;  /** XYZ 估计器 */
   MCAF_ESTIMATOR_INPUTS_T inputs;             /** 大多数估计器的公共输入 */
   MCAF_U_ANGLE_ELEC     theta;                   /** 估计的转子角度（电气） */
   MCAF_U_VELOCITY_ELEC  omega;                   /** 估计的转子速度（电气） */
   MCAF_RELATIVE_ANGLE_T thetaRelativeTo;
} MCAF_ESTIMATOR_T;

inline static bool MCAF_EstimatorQeiIsActive（const MCAF_ESTIMATOR_T* pestimator） { return false; }
inline static bool MCAF_EstimatorXyzIsActive（const MCAF_ESTIMATOR_T* pestimator） { return true; }

其中 MCAF_ESTIMATOR_T 在 system_init.h 中引用，作为主电机数据结构的一部分，因此 Xyz 估计器状态变量位于 motor.estimator.xyz。

在 MCAF 生成的代码中，可能有多个估计器同时运行，但恰好只有一个估计器是用于换相反馈的主估计器。

中的值 motor.estimator.thetaRelativeTo 是估计器的换相角度，相对于主估计器。这些值可用于调试或性能分析，并包括所有被选为 参考估计器。

该 MCAF_EstimatorXyzIsActive() 函数是一个常值，为每个估计器返回 true 或 false，以指示它是否为主估计器。

注意： 估计器固件接口中使用“活跃”一词目前是不正确的。参见 勘误 了解更多信息。

5.4.1.5. 入口点和方法¶

位置和速度估计器有几个入口点和方法。

入口点如下：

  • 初始化： MCAF_EstimatorXyzInit() 在整体初始化期间被调用。这发生在上电复位后不久，只执行一次，给估计器机会初始化自己的状态变量。某些估计器可能依赖其他估计器，在这种情况下还会调用函数 MCAF_EstimatorXyzSetupOutputDependencies() ，以提供对其他估计器输出的访问。

  • 电机启动时的重新初始化： MCAF_EstimatorXyzStartupInit() 在 主电机状态机 转入 STARTUP 状态时被调用。这给估计器机会在电机启动开始时重新初始化其状态变量。

  • 步函数： MCAF_EstimatorXyzStep() 在主控制速率下被调用，由 MCAF_CommutationStep() 在 commutation.c 中。

    某些估计器还可能有其他入口点，以与步函数相同的速率调用：

    • MCAF_EstimatorXyzInteractionStep() — 包含与其他 MCAF 模块紧密耦合的任何操作，并可访问完整的 motor 数据结构。（不鼓励这样做，因为它违反了模块化，但在某些情况下不可避免。）

    • MCAF_EstimatorXyzStartupDelayRequested() — 这是一个获取函数，允许估计器在某些点延迟启动进度，以便估计器完成自己的任务。

  • 活跃换相角度和速度的选择：在 commutation.c 中， MCAF_CommutationStep() 从可用的估计器中确定角度和速度，通常通过以下结构：

    if （MCAF_EstimatorXyzActive（pestimator))
{
   pestimator->theta = MCAF_EstimatorXyzCommutationAngle（&pestimator->xyz);
   pestimator->omega = MCAF_EstimatorXyzElectricalFrequency（&pestimator->xyz);
}

    编译器会优化掉非活跃估计器的此类代码块，其中 MCAF_EstimatorXyzActive() 在编译时已知为 false。

以下是与每个估计器相关的方法。

// 供 Xyz 估计器使用的状态变量结构
typedef struct tagMCAF_ESTIMATOR_XYZ {
   ...
} MCAF_ESTIMATOR_XYZ_T;

/**
 * 在复位时初始化 Xyz 状态变量。
 * @param xyz Xyz 状态变量结构
 */
void MCAF_EstimatorXyzInit（MCAF_ESTIMATOR_XYZ_T *xyz);

/**
 * 在启动电机前初始化 Xyz 状态变量。
 *
 * @param xyz Xyz 状态变量结构
 */
void MCAF_EstimatorXyzStartupInit（MCAF_ESTIMATOR_XYZ_T *xyz);

/**
 * 执行 Xyz 估计器的一个控制步。
 *
 * @param xyz Xyz 状态变量结构
 * @param pinput 公共输入信号（例如静止坐标系电压和电流）
 * @param pmotor 电机参数（例如电阻、电感等）
 */
void MCAF_EstimatorXyzStep（MCAF_ESTIMATOR_XYZ_T *xyz，
               const MCAF_STANDARD_INPUT_SIGNALS_T *pinput，
               const MCAF_MOTOR_PARAMETERS_T *pmotor，
               ...);

/**
 * 返回换相角度
 *
 * @param xyz 状态
 * @return 换相角度
 */
inline static MCAF_U_ANGLE_ELEC MCAF_EstimatorXyzCommutationAngle（
               const MCAF_ESTIMATOR_XYZ_T *xyz）
               { return ... }

/**
 * 返回电气频率
 *
 * @param xyz 状态
 * @return 电气频率
 */
inline static MCAF_U_VELOCITY_ELEC MCAF_EstimatorXyzElectricalFrequency（
               const MCAF_ESTIMATOR_XYZ_T *xyz）
               { return ... }

/**
 * 确定是否请求启动延迟
 *
 * @param xyz 状态
 * @param startupStatus 启动状态
 * @return 是否请求启动延迟
 */
inline static bool MCAF_EstimatorXyzStartupDelayRequested（
               const MCAF_ESTIMATOR_XYZ_T *xyz， MCAF_STARTUP_STATUS_T startupStatus）
               { return ... }

5.4.1.7. 勘误¶

  • 使用“活跃”而非“主”（DB_MC-4325;适用性：MCAF R4、R5、R6、R7）— “活跃”一词在 commutation.c 和 commutation_types.h 中使用不正确，将在未来版本中修复为“主”，包括将 MCAF_EstimatorXyzIsActive() 改为 MCAF_EstimatorXyzIsPrimary()。
