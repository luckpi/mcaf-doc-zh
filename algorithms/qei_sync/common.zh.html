5.4.3.3.1. 所有方法共有的实现问题¶

5.4.3.3.1.1. API qei_sync¶

每种反电动势同步方法都被设计为满足以下 API （适用于所有方法）：

  • 生成的代码位于 qei_sync 模块

  • 依赖关系： qei_sync 模块

    • 它可能依赖于 startup 和 qei 模块

    • 不依赖于 system_state 或 commutation 模块

    • 它不直接访问任何 HAL 函数

  • 状态数据位于 qei_sync 模块

    • 中 motor.estimator.qei.sync

    • 类型为 MCAF_QEI_SYNC_T

    • motor.estimator.qei.sync.complete 是一个标志，表示反电动势同步是否完成。要重新运行同步，将此标志设置为 false （使用实时诊断软件）。

  • 方法

    • MCAF_EstimatorQeiSyncInit() — 初始化函数，运行一次

    • MCAF_EstimatorQeiSyncStep() — 更新函数，在控制 ISR 中运行，返回动作标志以在某些状态中影响启动行为。这些动作标志仅在 启动状态中且状态码为 时有效 MSST_ALIGN 或 MSST_SPIN。返回值可以包含以下任何位标志：

      • MESACT_DELAY — 启动状态机将被延迟，并保持在当前状态

      • MESACT_SET_CURRENT `` --- ``MCAF_EstimatorQeiSyncOverrideCurrent() 将被调用

      • MESACT_SET_ANGLE — MCAF_EstimatorQeiSyncOverrideAngle() 将被调用

      • MESACT_SET_FREQUENCY — MCAF_EstimatorQeiSyncOverrideFrequency() 将被调用

    • MCAF_EstimatorQeiSyncIsComplete() — 返回同步是否完成

    • MCAF_EstimatorQeiSyncGetCommutationOffset() — 返回由 qei_sync 模块计算的换相偏移。此结果仅在同步完成时需要有效（否则此函数的返回值应被视为无效）

  • 覆写处理函数

    下面列出的处理函数是在 启动序列的适当阶段被调用的特殊方法。调用者提供指向特定数据的指针。这通过消除 startup 和 qei_sync 模块之间的耦合来促进模块化；模块间通信在 commutation 模块中进行。

    每个处理函数可以选择是否更改数据，通常声明为 inline static 以便空的处理函数会被优化掉。

    方法

    适用状态

    行为

    MCAF_EstimatorQeiSyncOverrideCurrent()

    MSST_SPIN

    可设置电流

    MCAF_EstimatorQeiSyncOverrideAngle()

    MSST_ALIGN

    可设置施加的电气角度

    MCAF_EstimatorQeiSyncOverrideFrequency()

    MSST_ALIGN

    可设置施加的电气频率

5.4.3.3.1.2. 重要数据元素¶

无论使用哪种 qei_sync 方法，以下数据成员均可用：

  • motor.estimator.qei.position.commutationOffset — 控制换相偏移，即在编码器的原始电气角度用于换相之前加上的角度。可以使用实时诊断工具在电机运行时修改换相偏移。任何此类更改应缓慢进行：建议的最大步进为 11 电角度（2000 脉冲）。大于此的步进变化可能导致 FOC 中的控制环失去同步。

  • motor.estimator.qei.position.commutationOffsetFromIndex — 这是在反电动势同步结束时提供的一个便捷计算，它测量在一个电气周期内相对于索引位置的换相偏移。当使用带有索引脉冲编码器的电机时， commutationOffsetFromIndex 的值将相当一致，与 QEI 外设启用时电机的起始位置无关。
