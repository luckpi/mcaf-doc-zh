8. 常见问题 (FAQ)¶

8.1. 联系 Microchip¶

我们鼓励您联系当地的 Microchip 代表以获取 motorBench® Development Suite 或 MCAF 的支持。欢迎反馈和意见！

有关 Microchip 支持资源的更多信息，请参见 motorBench® Development Suite 发行说明的“客户支持”节。

8.2. USB 兼容性¶

Microchip 确实制造了一些包含 USB 外设的电机控制器件（dsPIC33EPXXXMU806/810/814 系列）。应用框架目前不支持 USB，但我们正在考虑在未来支持。

8.3. RTOS 兼容性¶

我们计划研究使我们的应用框架既能满足电机控制的严格时序要求，又能与 RTOS 兼容的方法。这是一项未来的工作，目前尚不完整。

8.4. MATLAB® 和 Simulink®¶

我们的长期目标是同时支持使用 C 语言编程 PIC® 微控制器和 dsPIC® DSC 进行电机控制的客户，以及使用 MATLAB® 和 Simulink® 进行代码生成的客户。目前，电机控制应用框架面向依赖 MPLAB® X 和 XC16 C 编译器的电机控制项目，不支持 Simulink 代码生成。电机控制应用框架软件是手工编写的，具有可读性和高效性；Simulink 生成的 C 代码本质上不是为了阅读或编辑，而是为了快速原型设计和与仿真结果的充分等效而自动生成的，并受 MATLAB 代码生成引擎功能的限制。

我们正在考虑支持这两类客户的方法；至少在短期内，我们对使用 MATLAB 和 Simulink 的客户的支持可能通过一个单独的应用程序来实现，专门针对使用 Simulink。
