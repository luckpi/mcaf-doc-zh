6.6.8. 验证与板级调试¶

6.6.8.1. 概述¶

本节提供在创建并导入新板级定义后，首次使用 MCAF 调试自定义板的指导。

警告

在充分信任 motorBench 中的板级定义和板设计/构建之前，请使用限流电源为自定义板供电。

注意

不要尝试连接或启动电机 在首次编程 MCC 生成的代码后。请按照以下步骤操作以降低硬件损坏风险。

6.6.8.1.1. 推荐设备¶

除了所需的电机和自定义板外，我们推荐：

  • 非接触式电流探头（如 Chauvin Arnoux E3N 或 AEMC SL261），用于测量相电流。

  • 用于低压系统的三相交流发电机定子，作为电机负载的替代方案；例如， Delco Remy 10470688 21SI (24V 50A)。

6.6.8.1.2. 一般流程¶

在高层面上，我们建议使用新板时遵循以下步骤：

  1. 固件执行：板是否正常执行？（心跳 LED、PWM 通道、实时诊断连接）

  2. 验证开环电压运行

  1. 配置系统为开环电压运行

  2. 验证 PWM 运行：确保 PWM 输出正在切换。

  3. 验证 DC 母线 电压测量在预期范围内。

  4. 测试过流故障 功能。

  5. 验证电流测量。

  1. 验证闭环电流 控制。

6.6.8.2. 一般固件执行¶

寻找 CPU 正确执行和时序正确的迹象：

  • “心跳 LED”——如果板上有此 LED，正常运行时将以 1Hz 速率闪烁，或在故障状态下闪烁错误代码（见 外部接口）

  • PWM 通道——如果板未处于故障状态，PWM 低侧通道 (PWMxL) 将以 “最小影响”状态 按指定 PWM 频率切换。

  • 测试点 MCAF_TESTPOINT1（如有）——应有 PWM 开关频率的脉冲，表示 MCAF ADC ISR 执行的时间间隔。

  • 实时诊断 连接 (X2Cscope)——板应能与实时诊断软件通信。

如果这些不能正常工作，可能是 CPU 未以正确频率运行的问题。

6.6.8.3. 开环电压运行¶

该 测试框架 可用于在 开环电压模式 下运行控制器，其中 PWM 输出以强制换相频率驱动，输出以正弦变化的线间占空比驱动 PWM。每相具有单独的占空比，遵循空间矢量 PWM / 零序调制的特征双峰波形，如 图 6.11。

  • 确保板的电机端子开路（未连接任何电机或负载）

  • 按照 表 6.2 中的步骤准备控制器以使用开环电压控制进行验证。

6.6.8.3.1. 验证 PWM 运行¶

在电机与任何负载断开的情况下，缓慢增加逆变器的 dq 轴参考电压 motor.vdqCmd.d 从零开始。在每一步，观察以下内容：

  • 检查 PWM 输出的占空比是否以预期电气频率变化 motor.testing.overrideOmegaElectrical。

  • 验证 死区时间 是否如预期出现在数字栅极驱动信号中。

  • 确保晶体管导通瞬态正常。

  • 检查每个半桥输出，确保其在 0V 和 DC 母线电压之间如预期摆动。

6.6.8.3.2. 验证 DC 母线电压测量¶

如果可以使用可调电源操作板，在预期范围内上下调节，检查 ADC 读取的电压是否落在给定 DC 母线电压的预期容差范围内。

6.6.8.3.3. 验证硬件过流故障¶

  1. 通过将微控制器的过流检测输入连接到适当的电源轨来手动触发过流输入，具体取决于 peripherals.pwm.fault.polarity （见 自定义板级 schema）：

    • 至 Vss（polarity = active-low）

    • 至 Vdd（polarity = active-high）

  2. 验证 PWM 输出停止切换。

  3. 复位过流输入（如果使用 示例应用，按下主按钮）。

  4. 验证 PWM 输出重新开始切换。

6.6.8.3.4. 验证电流测量的缩放和极性¶

  1. 确保测试框架按 表 6.2

  2. 连接三相感性负载（交流发电机定子或测试电机）。

    注意

    如果使用电机，为防止反电动势影响测量，请采取以下任一方法：

    • 锁定转子使其不动

    • 将电气频率 motor.testing.overrideOmegaElectrical 设为零

  3. 增加 d 轴电压 motor.vdqCmd.d 逐步增加，直到适量电流（最大连续电流的 10-20%）流过电机相位。所需电压约为 \(\delta_1V_{dc}+IR\) 其中 \(\delta_1\) 为 死区时间，以占空比表示，IR 为电机绕组上的线对中性点电压降。每次增加 5–20 计数即可。

    警告

    根据电气角度 motor.thetaElectrical，一个电机相位的电流可能接近零，即使其他两相有电流流过。确保至少测量两个电机相位的电流，以确保电机相电流不过大。或者，使用足够大的 motor.testing.overrideOmegaElectrical 值以确保至少 5 Hz 电气频率，同时调节 d 轴电压，使电气角度平滑变化且所有相位均可见电流。

  4. 设置 motor.testing.overrideOmegaElectrical 为零，使电压和电流为直流。

  5. 用电流探头测量实际相电流，并与固件中 motor.iabc 结构中的数字化电流比较；测量值和数字化电流应在合理范围内。

  6. 验证正向数字化电流与 预期电流方向。

6.6.8.4. 闭环电流控制¶

在此步骤中，将使用感性负载（电机或定子）以闭环电流控制运行 MCAF，指令电流设为较小的期望值并叠加方波扰动。（示例见 图 5.27 中的 整定不良和整定良好的电流环示例）

此步骤的目标是确保测量电流 motor.idq 跟随指令电流 motor.idqCmd；应使用实时诊断软件检查这些电流的 d 轴和 q 轴分量。

使用 测试框架：

  1. 确保 MCAF 初始化为强制换相：

    1. 设置 systemData.testing.guardKey = 0xD1A6 (53670)

    2. 设置 motor.testing.operatingMode = 0
      （OM_DISABLED 以保持输出晶体管处于最小影响状态）

    3. 设置 motor.testing.overrides = 2
      （换相覆盖 以强制换相）

  2. 设置 motor.testing.overrideOmegaElectrical = 0 以强制固定换相角

  3. 设置 motor.idqCmdRaw.d 和 motor.idqCmdRaw.q 设为零

  4. 设置 motor.testing.operatingMode = 2
    （OM_FORCE_CURRENT 以闭环电流控制运行控制器，但禁用外环）

  5. 设置 motor.idqCmdRaw.d 设为适中值（例如额定连续电流的 10-25%；见 CURRENT_MAXIMUM_COMMAND 于 sat_PI_params.h）

验证测量的 d 轴和 q 轴电流（motor.idq.d 和 motor.idq.q）跟随各自的指令电流（motor.idqCmd.d 和 motor.idqCmd.q）。

添加扰动方波信号，如 测试框架所述，到 d 轴电流指令：

  1. 设置 motor.testing.sqwave.idq.q 设为零

  2. 设置 motor.testing.sqwave.idq.d 设为较小值（建议为 motor.idqCmdRaw.d 中使用的值的一半）

  3. 设置 motor.testing.sqwave.halfPeriod 设为中频（建议 10Hz–100Hz）

  4. 设置 motor.testing.sqwave.value 设为 1，以启用扰动

验证测量的 d 轴和 q 轴电流（motor.idq.d 和 motor.idq.q）跟随各自的指令电流（motor.idqCmd.d 和 motor.idqCmd.q）。
