6.3. 参数定制¶

自 MCAF R4 起，可通过 motorBench® Development Suite 的 Customize 页面进行参数定制，该页面提供对影响代码生成的各种参数的访问。

本节提供设置这些参数的额外指导。

请注意： MCAF 的设计使得可定制参数的默认值适用于大多数电机。如果不确定如何操作，最佳做法是使用每个参数的默认值。

6.3.2. 详细信息¶

6.3.2.1. 电流测量¶

已实现多种电流测量算法用于获取相电流测量值并将其适配用于磁场定向控制的反馈通道。每种方法有不同的硬件要求，可根据所选板的电流测量能力使用：

  • 单通道（“单分流”） — 需要 DC 母线电流分流电阻

  • 双通道（“双分流”） — 需要两个相电流分流电阻

  • 三通道（“三分流”） — 需要三个相电流分流电阻

R7 版本新增。

6.3.2.1.1. 单通道¶

单通道（“单分流”） 在不同逆变器开关状态下采样 DC 母线电流以重建三相电流。

R7 版本新增。

6.3.2.1.1.1. 最小时间窗口¶

最小时间窗口 \(t_{\mathrm{sample}}\) 使用单通道测量电流信号所需的时间。此时间加到 PWM 死区时间上，使得 \(t_{\mathrm{crit}} = t_{\mathrm{deadtime}} + t_{\mathrm{sample}}\)。

R7 版本新增。

6.3.2.1.1.2. ADC 触发延迟¶

逆变器开关状态与 ADC 采样点之间的延迟。此延迟可能是为避免因逆变器开关状态导致的电流信号振铃所必需的，振铃会降低单通道电流测量的精度。

R7 版本新增。

6.3.2.2. 估计器¶

6.3.2.2.1. 主估计器¶

必须选择一个位置和速度估计器用于换相和速度反馈。

MCAF R7 起可用的估计器：

  • AN1292 锁相环 (PLL)

  • 角度跟踪锁相环 (ATPLL)

  • 正交编码器

  • 零速/最大转矩 (ZS/MT)

R5 版本新增。

（此前此选择在 motorBench® Development Suite 的 Configure 页面中进行。）

6.3.2.2.2. 活动估计器¶

除主估计器外，还可选择附加估计器。（仅主估计器用于换相和速度反馈。）

建议在排查或验证时使用多个估计器——尤其是正交编码器，其具有更高的角度和速度精度。请注意，这将增加 CPU 和内存需求。

R4 版本新增。

6.3.2.3. 运行参数¶

6.3.2.3.1. 最小速度¶

最小速度 \(\omega_{\min}\) 在 MCAF R5 中从 Configure 页面移至 Customize 页面。它在 MCAF 中有两种用途：

  • 确定可调速度范围的下限

  • 在自动整定中，确定无传感器估计器模型的动态特性；无传感器估计器在低速时稳定性和性能较差，因此降低最小速度通常会导致速度控制环带宽降低以确保稳定性。

最小速度 \(\omega_{\min}\) 此前用作电机启动时的转换速度。自 MCAF R7 起， 启动速度 参数确定电机启动时的转换速度。

R5 版本新增。

6.3.2.3.2. 启动速度¶

确定电机启动时的转换速度 \(\omega_1\)，即从开环换相到闭环换相的转换。（MCAF R7 之前，最小速度 \(\omega_{\min}\) 被使用。）此参数受约束，使启动速度 \(\omega_1\) 必须大于或等于最小速度 \(\omega_{\min}\)。

R7 版本新增。

6.3.2.3.3. 最大速度¶

增加或减少最大允许速度指令，以标称电机速度的比例表示。默认值在大多数情况下足够。对于在标称速度以上有较宽弱磁范围的电机，增加此值可能是合适的。

R6 版本新增。

6.3.2.3.4. 满量程速度¶

满量程速度以标称电机速度的比例确定，控制 数值表示 。增加此值可允许更多防止溢出的设计裕量。

满量程速度， \(\omega_u\)与满量程电气频率成正比， \(\omega_{eu}\), as expressed in 公式 6.1，其中 \(N_p\) 为极对数。（另见 转矩产生与参考坐标系）

(6.1)¶\[\begin{aligned} \omega_{eu} &= N_p \omega_u \end{aligned}\]

R6 版本新增。

6.3.2.3.5. 外环控制器¶

外环控制器控制的变量有两个选择：

  • 速度

  • 电压

速度控制器参数可在整定页面中配置，而电压控制器 参数 可在 Customize 页面中配置。

R7 版本新增。

6.3.2.3.6. 凸极阈值¶

凸极比 \(\xi = L_q/L_d\) 帮助确定是否使用全凸极电机模型。这是一个更复杂的电机模型，用于某些算法如 ATPLL 估计器、 MTPA和 弱磁。全凸极电机模型考虑两个电感，但需要稍多的计算。由于大多数永磁电机是非凸极的， \(\xi \approx 1\) 且凸极性可以忽略，从而节省 CPU 周期。

此阈值设置使用全凸极电机模型的最小凸极性。如果不需要额外计算，可增加阈值以忽略凸极性。

R6 版本新增。

6.3.2.3.7. 压摆率（最大加速度/减速度）¶

可调整最大加速度（电动象限）和最大减速度（发电象限）。增加压摆率将增加加速或减速期间所需的电机电流。

确定再生期间的最大减速度必须谨慎：电机驱动器将机械能转化为电能，这些电能必须有去处，如电池或动态制动电阻。如果没有可行的能量出口，DC 母线电压将上升，直到电机控制器检测到并关断，或者某个电容或晶体管故障并以破坏性方式耗散这些能量。

R5 版本新增。

6.3.2.3.8. 动态电流限制类型¶

受控的 d 轴和 q 轴电流可以有固定限值，如果需要短时高电流瞬态，限值也可根据电机电流变化。动态电流限制有两个选项：

  • None

  • Simple

R7 版本新增。

6.3.2.3.9. 闭环停止¶

MCAF 中有三种停止模式影响 电机停止行为 在 STOPPING 状态中的。

  • 最小影响 PWM — 相电流迅速降至零。不允许估计器在停止期间运行。

  • 闭环电流 — 控制 q 轴电流至零。允许估计器在停止期间运行。

  • 闭环速度 — 控制速度至零。允许估计器在停止期间运行。

R7 版本新增。

6.3.2.3.9.1. 速度和时间阈值¶

有两个闭环停止参数用于定义电机被认为停止的条件，在状态机从 STOPPING 状态转换到 STOPPED 状态中的。

  • 速度阈值

  • 时间阈值

从 STOPPING 到 STOPPED的转换，电机速度必须下降并保持在速度阈值以下至少持续时间阈值。此实现是为了避免速度阈值以下的短时速度瞬态导致误停止。 图 6.1 显示了一个示例，速度阈值设为 75 RPM，时间阈值设为 1.0 s。状态机仅在时间阈值完全经过且电机速度仍低于速度阈值时才转换为 STOPPED。

R7 版本新增。

6.3.2.3.10. 惯性减速参数¶

当 停止模式设为最小影响 PWM时，有两个相关的惯性减速参数用于估计使电机停止所需的时间，然后才能安全重启：

  • 速度阈值

  • 时间

产生的惯性减速时间用于 STOPPING 状态 在进入 STOPPED 状态。

R5 版本新增。

6.3.2.4. 磁通控制¶

参见 磁通控制 节以获取更多信息。

6.3.2.4.1. 磁通控制方法¶

选择使用哪种 磁通控制 方法，从以下选项中：

  • “None”——d 轴参考电流将设为零

  • “基于方程”——从 弱磁 和 MTPA 算法确定 d 轴参考电流

R6 版本新增。

6.3.2.4.2. 电流限制：边界类型¶

矩形类型独立设置 d 轴和 q 轴电流限值。二次类型基于圆形函数的二次近似设置 q 轴限值。

另见 q 轴电流限值的计算 节以获取更多信息。

R6 版本新增。

6.3.2.4.3. 电流限制：Idmax¶

d 轴电流归一化到最大电流 Imax，其中 Imax = 电机和驱动器连续电流额定值的最小值。建议将电流限值设在电机去磁电流以下。

R6 版本新增。

6.3.2.4.4. 电流限制：Iqmax¶

q 轴电流限值分配为电流限值 Imax 的一部分，其中 Imax = 电机和驱动器连续电流额定值的最小值。仅在启用矩形边界类型时适用。

另见 q 轴电流限值的计算 节以获取更多信息。

R6 版本新增。

6.3.2.4.5. 弱磁：启用¶

此参数确定是否启用弱磁。

R6 版本新增。

6.3.2.4.6. 弱磁：电压限值¶

中使用的电压幅值限值 弱磁 (FW) 归一化到 DC 母线电压。计算 d 轴电流使稳态电压需求不超过此圆形限值。理想情况下选择限值使电机在进入 过调制之前刚好进入 FW 运行。较高的限值可能阻止电机进入 FW 区域。较低的限值保证 FW 运行，但代价是额外的功率耗散。

R6 版本新增。

6.3.2.4.7. MTPA：启用¶

此参数确定是否启用 MTPA。

R6 版本新增。

6.3.2.4.8. MTPA 显示计算¶

MTPA 没有任何用户可配置参数，但包含两个仅用于指示的显示值：

  • \(I_{\textnormal{dmax\_mtpa}}\) — 显示 MTPA 可能产生的最大 d 轴电流参考

  • \(G_{\textnormal{mtpa}}\) — 显示使用 MTPA 可能产生的最大转矩增益，相对于 MTPA 禁用时的最大转矩（\(I_d = 0\)）。

两者通常都很小，除非电机具有显著的转子凸极性和高磁通利用率。凸极磁通利用系数 \(\alpha_{\textrm{mtpa}} = (L_q-L_d)I_{\max}/\psi_m\) 是转子凸极性和磁通利用率的度量，表示气隙磁通相对于永磁体磁通可以发生多少变化。

最大 d 轴电流和最大转矩增益大致与 \(\alpha_{\textrm{mtpa}}{}^2\)成正比，因此将总电流能力加倍 \(I_{\max}\) 大致使 MTPA 请求的 d 轴电流和 MTPA 对转矩的贡献翻两番。

R6 版本新增。

  • “None”——不需要死区补偿

  • “逐相”——使用 逐相死区补偿算法

R6 版本新增。

6.3.2.5.2. 电流线性范围¶

确定最大幅值 \(I_\delta\) 用于计算单位扰动信号的电流线性范围 \(\hat{s}_{abc}\) — 见 逐相死区补偿 和 电流线性范围。

R6 版本新增。

6.3.2.5.3. 前向增益¶

确定前向通道中用于减轻高电气频率下死区失真影响的死区补偿增益。除非此类型死区补偿已用特定电机仔细测试，否则建议使用默认值零。见 前向通道增益 节以获取更多信息。

R6 版本新增。

6.3.2.5.4. 反馈增益¶

确定反馈通道中用于减轻低速下死区失真对无传感器估计器影响的死区补偿增益。增加此增益通常会改善低速下无传感器估计器的性能，但过大的增益可能导致电流指令跳变到正限值。见 反馈通道增益 节以获取更多信息。

R6 版本新增。

6.3.2.6. 故障检测¶

6.3.2.6.1. 欠压裕量¶

确定电机控制器因可用电压低于最小工作电压而关断的点。

R5 版本新增。

6.3.2.6.2. 过压裕量¶

确定电机控制器因电压超过最大工作电压而关断的点。

R5 版本新增。

6.3.2.6.3. 堵转检测：启用¶

确定 状态机 是否因 堵转检测 条件而进入 FAULT 状态。禁用堵转检测功能将从项目构建中排除堵转检测算法，降低平均 CPU 使用率和内存需求。MCAF R7 之前，堵转检测默认启用且不可通过 Customize 页面控制。

R7 版本新增。

6.3.2.7. 启动¶

该 启动序列 有多个可修改的参数。这些如 图 6.2。

6.3.2.7.1. 启动电流¶

启动电流幅值 \(I_{q0}\) 代表启动鲁棒性（越高越好）与降低电机功率耗散（越低越好）之间的权衡。将其降至 0.5 以下没有太大意义，0.5 指定最大连续电流的一半。

R4 版本新增。

6.3.2.7.2. 斜坡上升时间¶

电流斜坡上升时间 \(t_r\) 仅影响启动的初始状态，其中电流从零增加到最大幅值。电流斜坡上升时间应比 \(L/R\)慢，以代表平滑过渡，但比整体启动时间快。

R4 版本新增。

6.3.2.7.3. 对齐时间¶

某些电机，特别是具有大惯性和齿槽转矩的电机，可能通过对齐时间 \(t_{\mathrm{aln}} > 0\)更可靠地启动。默认值零在大多数情况下足够。

R5 版本新增。

6.3.2.7.4. 最小加速时间¶

增加最小加速时间 \(t_{\mathrm{acc}}\) 如果需要更慢、更温和的启动。

R4 版本新增。

6.3.2.7.5. 加速度 \(\alpha_1\)¶

增加或减少加速率 \(\alpha_1\) 以控制较快的第二加速阶段。较慢的加速通常不容易发生周期滑移，但耗时更长。

R4 版本新增。

6.3.2.7.6. 加速度 \(\alpha_0\)¶

增加或减少加速率 \(\alpha_0\) 以控制较慢的第一加速阶段。（注：此值归一化到 \(\alpha_1\)。）较慢的加速通常不容易发生周期滑移，但耗时更长。

R4 版本新增。

6.3.2.7.7. 保持时间¶

保持时间 \(t_h\) 控制启动序列在 HOLD 状态中停留的时间，在该状态下电气频率和电流均保持恒定，然后转换到闭环换相。

在大多数情况下零值即可。

R5 版本新增。

6.3.2.7.8. 速度阈值 \(\omega_0\)¶

降低速度阈值 \(\omega_0\) 将更早切换到较快的第二加速阶段。

（注意，阈值 \(\omega_{\min}\) 由 最小速度设置 下的设置确定。）

R4 版本新增。

6.3.2.7.9. 角度收敛速率¶

角度收敛速率控制使用 Classic 启动方法时从开环到闭环换相的过渡速度。

某些电机可能需要较低的值以确保平滑过渡到闭环换相，通常在 0.1°/ms–1.0°/ms 范围内。

R5 版本新增。

6.3.2.7.10. 启动算法¶

Classic 是 MCAF R1–R3 中提供的算法。 Weathervane 比 Classic 算法更快地过渡到闭环，在 R4 中添加。

ZS/MT + 初始位置校正 在 MCAF R7 中添加，且为 ZS/MT 估计器。

见 启动方法的选择。

R4 版本新增。

6.3.2.7.11. 主动阻尼：最大幅值¶

控制主动阻尼的幅值 \(I_\Delta\)。如果启动噪声大或不稳定，请减小此值。设为零以完全消除主动阻尼。

R4 版本新增。

6.3.2.7.12. 主动阻尼：最大增益¶

控制主动阻尼的反馈增益。如果启动噪声大或不稳定，请减小此值。

R4 版本新增。

6.3.2.7.13. 主动阻尼：速度阈值¶

确定启用主动阻尼的最小速度。确保选择估计器足够稳定可用于主动阻尼的速度。

R4 版本新增。

6.3.2.8. 过调制¶

参见 过调制 节以获取更多信息。

6.3.2.8.1. d 轴限值¶

确定最大 d 轴电压。建议保持 1.0。

R4 版本新增。

6.3.2.8.2. q 轴限值¶

确定最大 q 轴电压。建议值在 1.05 到 1.25 之间。较大的值允许更高的输出电压幅值，但代价是输出电压和电流的失真更高。

关于 同步坐标系中的过调制行为 节有更多关于此主题的信息。

R4 版本新增。

6.3.2.8.3. 带削波的占空比反馈¶

确定活动估计器的占空比反馈是在零序调制 (ZSM) 和因 过调制削波之后获取。如果未选中，占空比反馈将在 ZSM 和削波之前获取。

R7 版本新增。

6.3.2.9. AN1292 PLL¶

参见 AN1292 锁相环 (PLL) 节以获取更多信息。

6.3.2.9.1. 时间常数¶

确定时间常数 \(\tau\) 用于速度估计。这不影响估计器稳定性，但影响速度控制环性能。较低的时间常数值允许更多噪声通过，但允许更高带宽的速度环。较高的时间常数值滤除更多噪声，但降低可实现的速度环带宽。

R5 版本新增。

6.3.2.9.2. 环路滤波器带宽¶

确定环路滤波器带宽 \(\omega_1\) 用于 PLL 中的角度估计。（注：此值与启动速度不同，也称为 \(\omega_1\)）

建议保持默认值。

R5 版本新增。

6.3.2.9.3. 滤波器阈值¶

确定 PLL 估计器中慢速滤波的最大速度。建议保持默认值。

R6 版本新增。

6.3.2.10. 正交编码器¶

参见 正交编码器支持 节以获取更多信息。

6.3.2.10.1. 线数¶

应与电机或编码器数据手册中列出的线数或每转周期数 (CPR) 匹配。每转计数数为线数的 4 倍。

R4 版本新增。

6.3.2.10.2. 存在索引脉冲¶

如果存在索引脉冲信号，请选择此选项。

R4 版本新增。

6.3.2.10.3. 跟踪环路时间常数¶

建议值在 1 ms–10 ms 范围内。较小的值将增加估计器带宽，但允许更多编码器量化噪声出现在速度估计中。较大的值将降低估计器带宽和可实现的速度环带宽，但会降低编码器量化噪声的影响。

注： 在 MCAF R4 中，对于低速电机和跟踪环路时间常数的某些组合，代码生成会出现超范围错误。这在 \(\omega_{m1} \tau < \theta_L\) 时是预期的，其中 \(\theta_L \approx 0.4\ \text{rad}\)，其中 \(\omega_{m1}\) 为额定电机速度（rad/s）， \(\tau\) 为跟踪环路时间常数。在大多数情况下，可行的解决方法是增加跟踪环路时间常数，但这会降低速度环带宽。

例如，额定速度为 2000 RPM ≈ 209 rad/s 的电机，如果跟踪环路时间常数小于约 \(0.4 / 209 = 0.0019\) s 或 1.9 ms，则可能出现超范围错误。

R4 版本新增。

6.3.2.10.4. 同步方法¶

  • 对齐——最佳通用同步方法，最快，对大齿槽转矩敏感

  • 失步——对齿槽转矩最不敏感，对大惯性敏感

  • 对齐扫描——慢，精度最佳

R4 版本新增。

6.3.2.10.5. 对齐时间¶

确定用于反电动势同步的对齐时间。较大惯性的系统可能需要更长的时间。较短的时间（小于 0.5 s）对于极低惯性系统可能足够。

R4 版本新增。

6.3.2.10.6. 对齐角度偏移¶

对于高齿槽转矩的系统，请增加此角度。建议值为 30°–60°。

R4 版本新增。

6.3.2.10.7. 对齐初始角度¶

控制启动斜坡上升状态期间使用的初始电气角度。某些角度可能略微更鲁棒，但必须针对特定电机通过实验确定。

R4 版本新增。

6.3.2.10.8. 对齐扫描速率¶

每 ISR 4 计数是最快的，适用于大多数低齿槽转矩的电机。对于高齿槽转矩的电机，请减小此值。

R4 版本新增。

6.3.2.10.9. 对齐扫描设置角度¶

控制进行换相偏移测量之前的设置角度。较小的值可能没有足够时间让瞬态稳定。较大的值会增加瞬态稳定时间。对于高惯性系统，增加此值可能提高精度。

R4 版本新增。

6.3.2.10.10. 失步滑差阈值¶

此参数控制测量失步偏移以确定换相偏移时的滑差。此处滑差定义为静止坐标系电压矢量角度与编码器原始电气位置之间差值的变化率 \(V_{\alpha\beta}\) 。此参数的良好选择取决于电机的机械特性，即惯性 \(J\)、粘性阻尼 \(B\)和摩擦转矩 \(T_{fr}\)。对于低惯性电机，滑差阈值可能需要增加；对于高惯性电机，可能需要减小。滑差阈值的推荐范围约为 0.059 到 0.47 rad/s。（默认值的 0.5 倍到 4 倍）

R4 版本新增。

6.3.2.11. 动态电流限制¶

以下参数控制简单动态电流限制算法的行为。参见 动态电流限制 节以获取更多信息。

  • 峰值电流——确定绝对峰值电流 \(I_{\mathrm{peak}}\)。

  • 基准电流——确定基准电流 \(I_{\mathrm{horz}}\) 用于简单动态电流限制算法。电流限制松弛到基准电流。

  • 时间常数——松弛时间常数 \(\tau\) 确定电流限制松弛到基准电流的速度。

  • 抽取比——确定抽取比 \(N\) 用于每 \(N\) 个电流控制环样本执行一次动态电流限制算法。

R7 版本新增。

6.3.2.12. 电压控制¶

6.3.2.12.1. 低通滤波器时间常数¶

时间常数 \(\tau_{\mathrm{lpf}}\) 用于衰减电流控制器输出噪声的一阶低通滤波器 \(V_q\)。

R7 版本新增。

6.3.2.12.2. 比例增益¶

比例增益 \(K_p\) 在外环控制器中当电压为受控变量时使用。此参数必须手动整定；参见 电压控制 节以获取指导。

R7 版本新增。

6.3.2.12.3. 时间常数¶

时间常数 \(\tau\) 在外环控制器中当电压为受控变量时使用。此参数设置 \(K_i\) 电压控制器的增益，使用 \(\tau = K_p/K_i\)。此参数必须手动整定；参见 电压控制 节以获取指导。

R7 版本新增。

6.3.2.13. 运动控制 API¶
