详细：

7.5.2.1. MCAF R2 RC9¶

7.5.2.1.1. 添加/移除的模块¶

  • atan2cordic 被移除（其他模块不需要）

  • board_service， filter、 units 已添加

7.5.2.1.2. 核心 FOC¶

  • 逆 Clarke 变换已被其常规变体替代。（MCAF R1 交换了 \(\alpha\) 和 \(\beta\)）

  • 带相移输入的空间矢量调制已被 零序调制 的实现替代，包含削波以实现 过调制。

7.5.2.1.3. 过调制¶

过调制 支持已添加。

7.5.2.1.4. DC 母线补偿¶

DC 母线补偿 支持已添加。

7.5.2.1.5. 扩展了支持的电机范围¶

  • 在广泛的电机参数范围内测试了参数生成，以识别和纠正范围问题。

  • 若干移位计数改为在代码生成时选择（而非固定 Q15）。

  • 若干时间延迟值（主要在启动和堵转检测中）改为使用 32 位计数，以支持更长的时间常数。

  • 部分 PLL 计算被重写以防止溢出。

7.5.2.1.6. 缩放因子和运行范围¶

  • 电压的缩放因子已统一为基于最大 DC 母线电压的一个值。

  • 电机速度的缩放因子已改为电机基速的 1.5 倍；MCAF 中已添加从 motorBench® Development Suite 覆盖此值的功能，尽管截至 motorBench® Development Suite 1.35 版本此功能尚不可用。

  • 最小运行速度现在基于 motorBench® Development Suite 迁移现有数据。

7.5.2.1.7. 故障检测¶

  • 堵转检测的转矩角方法被重写以提高在更宽电机范围内的精度。

  • 堵转检测的 Ed 方法被调整以移除阻碍某些电机堵转检测的低通滤波。

  • 该 monitor 模块被重写为简单的状态机 以避免意外行为。

7.5.2.1.8. 测试框架¶

  • 添加了 强制状态变更 （例如 STOPPING → STOPPED ）

7.5.2.1.9. HAL¶

  • 添加了新接口用于 TMR1 （硬件定时器 1）

  • 添加了附加函数用于 UART1

  • 重构了 BSP 中的部分应用接口，将 LED 和测试点相关接口移至 HAF

  • 添加了新 板级服务模块

7.5.2.1.10. 电机控制库¶

MCAF R2 包含的电机控制库版本添加了大量新函数，包括带削波的零序调制和常规逆 Clarke 变换。

请不要在 MCAF 之外的其他项目中使用此版本的电机控制库。

7.5.2.1.11. 杂项¶

MCAF 版本信息（“R2/RC9”以及提交 ID 和构建日期）已添加到库之外的所有 C 源文件中。

7.5.2.2. MCAF R3 RC14¶

致读者：从此版本开始，您可能会在修订历史中看到括号中列出的问题跟踪键，如 DB_MC-97。这些键用于帮助 Microchip 工作人员根据需要引用更详细的信息。

7.5.2.2.1. 添加/移除的模块¶

该 meas_curr 模块（用汇编编写）已与 foc 模块的部分功能合并，形成新的 adc_compensation 模块（用 C 编写）。（DB_MC-97、DB_MC-675）

7.5.2.2.2. MCC 兼容性¶

MCAF 现在与 MCC 系统模块兼容，包括振荡器设置。（DB_MC-1679、 DB_MC-1688、DB_MC-1689、DB_MC-1690）

  • 先前的 traps 和 main 模块已被重命名 mcaf_traps 和 mcaf_main。（DB_MC-1685、DB_MC-1686）

  • 现在还有一个 mcaf_main.h 用于包含函数声明。（DB_MC-1846）

  • MCAF 不再负责生成 main()；而是由 MCC 的 main() 函数调用 MCAF 进行初始化和主循环。

  • MCAF 已将配置位生成的责任交给 MCC

  • MCAF 已将振荡器配置的责任交给 MCC（DB_MC-1849）

  • HAL 中的某些函数已使用 MCAF_ 前缀重命名，以避免与 MCC 生成的 HAL 函数的名称冲突。

MCAF 仍不与 MCC 的其他模块（包括 ADC、UART 和 PWM）兼容。MCAF 内的 HAL 负责配置和使用这些模块。

参见 HAL 的文档以获取更多信息。

7.5.2.2.3. MCHV-2 和 MCHV-3 兼容性¶

MCAF 生成的 HAL 现在完全兼容 MCHV-2 和 MCHV-3 开发板。（MCAF R2 确实包含 MCHV-2/MCHV-3 所需的 HAL 函数，但始终为 MCLV-2 生成代码。）

7.5.2.2.4. 缩放因子和运行范围¶

在 motorBench® Development Suite 中输入的连续额定逆变器电流现在精确等于最大 dq 轴 指令电流幅值。在 MCAF R2 中，应用了 0.824 的降额系数。（DB_MC-1307）

7.5.2.2.5. ADC 补偿¶

ADC 电流增益矩阵现在动态生成。在 MCAF R2 中，它固定为支持未修改的 MCLV-2 板。现在可以处理 motorBench® Development Suite。（DB_MC-1332）

7.5.2.2.6. 核心 FOC¶

  • PLL 现在使用 motor.valphabetaOut rather than motor.valphabeta。（DB_MC-1164）这些状态变量之间的区别在于 motor.valphabeta 表示在 \(V_{\alpha\beta}\) prior to 零序调制, whereas motor.valphabetaOut 表示基于 PWM 占空比计算的实际 \(V_{\alpha\beta}\) 的最佳估计。两者在电流控制器 进入 过调制之前是相同的。另请参见 MCAF_ComputeVAlphaBetaAtOutput()。

7.5.2.2.7. 故障检测¶

  • 转矩角堵转检测默认已禁用。（DB_MC-1732） 参见 监督勘误 的文档以获取更多信息。

  • MCAF_VarianceDetectx16Decimate() 已重命名为 MCAF_VarianceDetectx16PostDecimation() 以提高清晰度。（DB_MC-846）

7.5.2.2.8. 测试框架¶

  • 添加了 导致堆栈溢出。（DB_MC-1708）

  • 添加了 换相覆盖的延迟循环。（DB_MC-1280）

  • DC 母线补偿可通过设置相应的覆盖位来禁用。（DB_MC-1168）

7.5.2.2.9. HAL¶

  • 添加了 QEI 和 PWM 模块的附加函数

  • 移除了配置位和振荡器初始化

  • 重命名了 pin_manager， interrupt_manager、 mcc 模块中的函数，使用 MCAF_ 前缀重命名，以避免与 MCC 生成的 HAL 函数的名称冲突。

7.5.2.2.10. 电机控制库¶

内联汇编中的一个小错误在 MC_adjust_zero_sequence 中的一个小错误已修复。（DB_MC-1403） 这表现为构建失败（Error: Invalid operands specified ('add w0,[w15-10],w8').）在使用 -O0构建时；提醒一下，MCAF 需要优化级别 -O1 或更高才能满足时序约束。

未进行其他更改。

MC 库的更新文档尚不可用。

请不要在 MCAF 之外的其他项目中使用此版本的电机控制库。

7.5.2.2.11. 代码生成¶

  • 改进了遇到超出范围错误时的代码生成错误消息。（DB_MC-1435）

  • 改进了代码生成中计算参数的内部机制。（DB_MC-1706、DB_MC-1760）

  • 过压和欠压裕量现在设置为 MCLV-2 的 2V 和 MCHV-2 的 20V。（DB_MC-1734） motorBench 的未来版本® Development Suite 将允许编辑这些值。

7.5.2.2.12. 辅助报告¶

  • aux-files/report.html 中的派生参数列表已扩展。（DB_MC-1178）

  • aux-files/ 中的报告现在包含对相应 MCAF 版本的可追溯性。（DB_MC-1364）

  • 更新了 KaTeX 到更新的版本。（DB_MC-1517）

  • 修复了 report.xml 中的错误，具体为缺少闭合标签（DB_MC-1572）

  • 文件 report.xml 已重命名为 report.xml.txt 以避免在 MCC 中触发错误。（DB_MC-1868）

7.5.2.2.13. 杂项¶

  • MCAF 版本信息已更新为“R3/RC14”。

  • MCAF 版权日期已更新为 2018 年。（DB_MC-1788）

  • 类型头文件已从 ui 和 startup 模块中分离——现在有 ui_types.h 和 startup_types.h。（DB_MC-470）

  • 某些状态变量已从 int16_t 更新为适当的单位 typedef，如 MCAF_U_VELOCITY， MCAF_U_VOLTAGE_ALPHABETA， MCAF_U_DIMENSIONLESS_SINCOS等。（DB_MC-1199、DB_MC-1281）

7.5.2.3. MCAF R4 RC12¶

7.5.2.3.1. 添加/移除的模块¶

  • 该 pll 模块已移至 commutation/pll

  • 该 qei 模块已移至 commutation/qei

  • 该 watchdog 模块已临时重命名 mcaf_watchdog 直到与 MCC 的冲突得到解决。（DB_MC-2175）

7.5.2.3.2. MCC 兼容性¶

MCAF 外设和系统初始化代码生成完全由 MCC 处理。唯一的例外是 QEI 外设，因为 MCC 尚不支持此功能。（DB_MC-2146）

  • 已添加 HAF 函数以使用新的 MCC PWM API。（DB_MC-2089）

  • 已添加用于获取中断向量号的 HAF 函数。

参见 HAL 的文档以获取更多信息。

7.5.2.3.3. 正交编码器支持¶

MCAF 以 16 位值和选定的 32 位状态变量为目标进行定点数学运算。这足以处理 12 位 ADC 输入并满足滤波器、积分器和其他时间相关算法的量化需求。浮点支持（仅 dsPIC33A）计划在未来版本的 MCAF 中实现。

支持的器件：

  • dsPIC33AK(32/64/128)MC10x

  • dsPIC33AK(256/512)MC5xx

这些器件使用 XC-DSC 3.21 或更新版本。

7.5.2.8.3. ADC 校准与补偿¶

  • 改进了电流偏置校准以允许在 Customize 页面中更宽的最大范围，如果超出可接受的限制则产生故障（DB_MC-5542、DB_MC-4924、DB_MC-4180）

  • 修正了 adc_compensation_types.h 中的注释，将增益值描述为 Q14 而非 Q15（DB_MC-6286）

  • 实现了 dsPIC33AK 器件的 ADC 增益补偿（DB_MC-5956）

7.5.2.8.4. 测试框架¶

  • 添加了施加有意偏移的选项，用于测试电流校准（DB_MC-6254）

7.5.2.8.5. 开发板支持¶

  • 添加了对 MCHV-230VAC-1.5kW 电机控制高压开发板 （DB_MC-4607）

  • 添加了 50ms 上电延迟以防止电流涌入脉冲导致的误触发过流故障 MCS MCLV-48V-300W 开发板 （DB_MC-6293）

  • 修正了 MCS MCLV-48V-300W 开发板 连续电流限制（DB_MC-5781）

7.5.2.8.6. 自定义板级支持¶

  • 添加了在自定义板级配置中将引脚重新映射到 PCIxR PWM 故障源的选项（DB_MC-6007）

  • 在生成的 hal_params.h 中包含板级 ID，以增加可追溯性和上下文（DB_MC-6185）

  • 将电位器 ADC 信号移至可选输入；不再需要电位器（DB_MC-6225）

  • 添加了可选的上电延迟（DB_MC-6252）

7.5.2.8.7. HAL¶

  • 从 MCAF HAL 中移除了比较器 DAC 配置以改用 MCC 配置（DB_MC-6023、DB_MC-6160）

  • 修复了 HAL_PWM_PhaseBOutput_Enable 错误地禁用了高侧输出但未禁用低侧输出的问题（DB_MC-6040）

  • 更改了 HAL UART 函数使其仅在所选板级上有 UART 时才生成（DB_MC-5701）

7.5.2.8.8. MISRA 合规性¶

通过解决以下三条规则减少了大量 MISRA 违规：

  • 规则 1.5：不应使用过时的语言特性——使用 void 在无参数函数的函数参数列表中使用 void（DB_MC-6034）

  • 规则 15.7：所有 if - else if 结构都应以 else 语句终止（DB_MC-5941）

  • 规则 21.1：不应在保留标识符或保留宏名称上使用 define 和 undef 指令（DB_MC-5939）

7.5.2.8.9. motorBench® Development Suite Customize 页面支持¶

  • 修复了阻止使用可选模拟输入的错误（DB_MC-6269）

  • 提供了 ATPLL 估计器的整定参数（DB_MC-5110）

  • 添加了通过 Customize 页面启用/禁用测试框架和测试性能分析的选项（DB_MC-5874）

  • 在 Customize UI 中包含黄色指示器以提示发行说明中的进一步指导（DB_MC-6196）

7.5.2.8.10. 启动¶

  • 将主动阻尼电流限制为最大启动电流（DB_MC-4559）

7.5.2.8.11. 零速/最大转矩 (ZS/MT) 估计器¶

  • 各种 bug 修复和改进 ZS/MT 算法的各种改进 （DB_MC-5442）

7.5.2.8.12. 杂项固件改进和问题¶

  • 修正了中的抗积分饱和注释 MCAF_ControllerPIUpdate() 在 sat_PI.c 中（DB_MC-4751）

  • 确保诊断 UART TX 引脚在初始化时设置为输出高电平（DB_MC-5652）

  • 修复了使用与 ABC ⇔ PWM123 不同的电机相到 PWM 映射时的看门狗超时问题（DB_MC-5788）

  • 移除了未使用的 motor.potInput 并将关联状态移至 APPLICATION_DATA 在示例应用中（DB_MC-5838）

  • 修复了外环电压环的代码生成（DB_MC-6097）

  • 添加了参数到 MCAF_FilterLowPassS16Init 以指定初始滤波器状态（DB_MC-6292）

  • 修复了 MCAF_BootstrapChargeInit 在 gate_drive.c 中以引用符号 MCBS_IDLE_START 而非其零值（DB_MC-6389）

  • 移除了 Q15、Q14、Q13 等宏的使用（DB_MC-698）——MCAF 在代码生成时 在 parameters 目录头文件中使用更结构化的机制

  • 移除了空白的 commutation_params.h 文件（DB_MC-4867）

  • 包含了浮点 #define 宏到生成的参数文件中每个可配置参数（DB_MC-5536）

  • 将软件过流“堵转”检测器更改为默认禁用（DB_MC-5569）

  • 从固件包中移除了剩余的 RTDM 内容（DB_MC-5664）

  • 更改了所有 MCAF 头文件中的包含保护以使用 #ifndef 标识符以 MCAF_ 前缀（DB_MC-5977）

  • 提供了 UTIL_DivQ15 在 util.h 中而非处理器特定的内建函数中（DB_MC-6079）
