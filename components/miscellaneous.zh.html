4.11. 杂项¶

其他一些模块与 MCAF 的行为没有直接关系，但对数学例程等领域有所贡献。

4.11.1. 实现说明¶

4.11.1.1. 模块¶

模块

文件

描述

说明
atan2cordic
atan2cordic.s

C 可调用的反正切 CORDIC 实现， atan2CORDIC()

这包含 Q15 CORDIC 的汇编实现，可能被放弃或替换为 C 实现。
filter
filter.h
filter_types.h

一阶低通和高通滤波器

math_asm
math_asm.h
math_asm.s

实用数学例程

这包含 Q15 定点平方根的汇编实现 Q15SQRT() 可能被以下两种替代方案之一替换：

  • 完全不使用平方根（目前它涉及矢量电流环中的饱和处理逻辑）

  • 使用 _Q15sqrt() 函数，该函数位于标准 libq 库的 16-Bit Language Tools Libraries
motor_control_function_mapping
motor_control_function_mapping.h

util
util.h
util_types.h

杂项实用和数学函数

包含大量带有前缀 UTIL_ 的内联实用函数，用于 Q15 数的平方（对 -32768 的修正）、将值限制在最小值和最大值之间等。

基本上所有有复用潜力的小函数都被重构并放置在此模块中。
