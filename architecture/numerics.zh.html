3.8. 数值算法处理¶

3.8.1. 数值表示¶

MCAF 目前仅使用定点（而非浮点）计算。大多数状态变量和参数表示为 Q15 定点数，存储在有符号 16 位整数（int16_t），还有少量 32 位值（通常在积分器或滤波器状态中）和少数无符号 Q15 16 位值。某些增益在适当时使用其他缩放因子（如 Q11 或可变移位）。

3.8.2. 代码中的常量¶

如果选择常量值的原因不明确，代码中的常量有时被认为是“魔数”。我们尽量避免在电机控制应用框架中出现这种情况。

电机控制应用框架中使用的常量通常分为五类之一。

  1. 自动计算的值：在 parameters/ 目录中，在头文件或 C 运行时初始化函数中——这些值由 motorBench® Development Suite 在自动整定和代码生成步骤中计算。我们不建议手动更改这些值。对于定点整数常量，通常会附带注释，指示浮点等效值和相应的工程值，以及量化精度，例如：

    #define KIP             8696    // Q15(  0.26538) = +414.67629 mV/A     = +414.65940 mV/A    + 0.0041%
#define KII              643    // Q15(  0.01962) = +613.24024 V/A/s    = +613.20687 V/A/s   + 0.0054%

    在许多其他任务中，我们正在努力改进代码中的文档，以阐明这些常量是如何计算的，或者至少它们依赖于哪些因子。在某些情况下，这些计算是 motorBench® Development Suite 的 自定义页面上设置。

  2. 硬件抽象层的一部分：在 hal/ 目录中。这些旨在与 MCC 自动生成的输出保持一致，并最终被其替换。

  3. “显而易见”的值（位于 C 源文件中） 在 parameters/ 目录之外的 C 源文件中，包括下面的一些示例。在这些情况下，将它们隐藏在抽象的符号常量后面反而会模糊而非澄清其用法。如果您发现某个示例中它们似乎不合适，请告知我们，我们将考虑替代方案。

    • 0

    • +1 或 -1 作为符号/方向值

    • 最大表示值，如 0xFFFF 或 0x7FFF

    • 移位计数，例如 >> 16 当从 int32_t 转换为 int16_t，或 >> N 其中乘以 QN 定点数时，N 的值在代码注释中说明

    • 循环展开的数组索引

    • MCAF_DelayNanoseconds(500); （用于输出“短脉冲”，如随附注释中所述）

  4. 手工计算的常量，附带注释解释其推导过程 ——这些不常见；如果有任何不明确之处，请告知我们。

  5. 遗留代码常量 ——如果由于某种原因您注意到代码中的常量不属于上述任何类别，那可能是疏忽，在这种情况下请告知我们。
