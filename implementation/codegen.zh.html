6.2. 代码生成¶

6.2.1. 与 motorBench 的关系® Development Suite 和 MCC¶

MPLAB® Code Configurator (MCC) 可作为 MCC 的插件库与 motorBench® Development Suite 一起使用。每个版本的 motorBench® Development Suite 都包含一个固件包，用于生成特定版本的 MCAF。

自 MCAF R4起，所有外设和系统初始化代码均由 MCC 而非 MCAF 生成。唯一的例外是 QEI 外设，MCC 尚不支持 dsPIC33E 器件的该外设，需要在 MCC 中设置某些外设、振荡器和配置位。详见 motorBench® Development Suite 帮助文档和发行说明以获取更多信息。

自 MCAF R7， QEI 外设也包含在 MCC Melody 生成的外设和系统初始化代码中。MCAF 不再负责生成任何外设和/或系统初始化代码。这样 MCAF 可以利用 MCC Melody 来扩大对器件和硬件的支持。MCC Classic（33EP 器件所需）不支持 QEI 外设，因此 MCAF 为该器件提供了适当的实现以替代代码生成。

6.2.2. 可配置参数¶

生成的文件位于 parameters 目录中，包含根据 motorBench® Development Suite 和 MPLAB® Code Configurator 中输入或推导的信息计算得出的可配置参数。

Microchip 正在研究使这些参数计算更加透明、更易于在必要时调整的方法。

6.2.2.1. 超范围错误¶

在少数情况下，配置参数可能在代码生成期间产生错误。这可能是由于电机参数与典型电机相比过大或过小。此时，代码生成将失败，并在 MPLAB® Code Configurator 中显示错误消息。（请阅读 motorBench® Development Suite 的发行说明以了解这些消息的显示方式。）

典型的超范围错误消息如下所示：

ValueError： Value 'kip' out of range： 345.055 Q8.8 = 4140.66 V/A

在此例中，代码生成引擎试图将实际值 4140.66 V/A 转换为 Q8 表示的 345.055，该值过大；Q8 仅支持 ± 128。

Microchip 正在研究提供超范围错误排查和纠正指南的方法；在此期间，如果您遇到超范围错误，请 联系 Microchip 寻求帮助。

6.2.3. 源文件组织¶

每个源文件以如下头部开始：

代码清单 6.2 foc.c¶
/**
 * foc.c
 *
 * 主磁场定向控制代码
 *
 * 组件：FOC
 */

/* *********************************************************************
 *
 * 电机控制应用框架
 * R3/RC14 (commit 90529, build on 2018 Oct 04)
 *
 * (c) 2018 Microchip Technology Inc. 及其子公司。您可以使用
 * 此软件及其任何衍生品仅与 Microchip 产品配合使用。
 *
 ...

这是两个注释块。

第一个用于某些计算机辅助文档，包含文件名、简要描述和 组件 名。

第二个注释块包含 MCAF 版本（例如，R3 = 第 3 版，RC14 = 第 14 个候选发布版）、提交 ID 和构建日期，以及版权声明。

通常，每个 模块 的代码分为两到三个文件，例如 foc 模块：

  • 编译单元（foc.c）——包含可 C 调用的函数定义

  • 头文件：

    • 主头文件（foc.h）——包含函数声明和内联函数实现

    • 类型头文件（foc_types.h）——包含与函数声明分离的类型定义

除类型头文件外，这是 C 代码中的典型组织方式。类型头文件被分离出来是为了帮助消除模块间不必要的依赖，使得状态变量可以在不引入额外模块依赖的情况下进行分配。

6.2.4. 辅助报告¶

MCAF 包含在 aux-files 目录中生成的若干附加文件：

  • parameters.html ——一个 可配置参数表。

  • report.html ——一个电机参数和指标表。如果您在排查特定电机的行为时需要帮助，请将此文件提供给 Microchip 工作人员，以便他们更好地了解电机的特性。派生参数或指标如 \(\tau_e = L_s/R_s\) 和 \(\tau_{m1} = JR_s/\frac{3}{2}{K_e}^2\) 和 \(\alpha_J = \tau_{m1}/\tau_e\) 可以帮助解释某些观察结果，或引导经验丰富的电机控制工程师指出使用该特定电机时的某些挑战。电气时间常数 \(\tau_e\) 和机械时间常数 \(\tau_{m1}\) 等时间常数可以帮助说明电气和机械动态的时间尺度。归一化惯量 \(\alpha_J\) 是这两个时间常数的比值，可以突出系统是否具有小惯量（\(\alpha_J < 2\)），此时电气和机械动态不能很好地分离，可能导致控制稳定性挑战；或大惯量（\(\alpha_J \gg 1\)），此时可以预期速度控制环较慢。

  • report.json ——机器可读的电机参数值，采用 JSON 格式。

  • report.xml.txt ——机器可读的电机参数值，采用 XML 格式。

这些文件是实验性的。欢迎任何关于改进这些文件内容的意见或建议；请 联系 Microchip。
