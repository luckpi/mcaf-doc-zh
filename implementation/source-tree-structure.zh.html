6.1. 源代码树结构¶

MCAF 被组织为若干子目录。与 motorBench® Development Suite 一起使用时，这些目录生成在 MPLAB® X 项目目录下的 motorBench/generated_code。

  • 大多数模块位于顶层目录下。

  • hal 包含 硬件抽象层

  • parameters 包含带有 可配置参数的头文件。

  • library 包含 电机控制库的库文件

  • aux-files 包含非 C 代码的辅助文件，例如由 motorBench 生成的报告文件® Development Suite.

特定源代码文件的信息按模块名组织，位于 index 的“modules”条目下。（模块名即文件的基础名，忽略文件扩展名以及可能存在的尾部 _types：例如， commutation.c， commutation.h，以及 commutation_types.h 都属于 commutation 模块。）
